# ADWJ 网站

爱达无界官网 + 管理后台

## 项目结构

- `web/` - 展示网站（React + Vite）
- `admin/` - 管理后台
- `supabase/` - 数据库脚本

## 技术栈

- React 19 + TypeScript + Vite
- Tailwind CSS
- Supabase（数据库 + 存储）

## 本地开发

```bash
# 展示网站
cd web
npm install
npm run dev

# 管理后台
cd admin
npm install
npm run dev
```

## 部署

- 展示网站：Vercel
- 管理后台：Vercel（独立域名）
